KONFIGURACJA FIREBASE

Otwórz plik w edytorze i wklej swój config na samej górze skryptu (FIREBASE_CONFIG).

  1. console.firebase.google.com → nowy projekt
  2. Build → Realtime Database → Create (wybierz region europejski)
  3. Project settings → Your apps → Web (</>) → skopiuj config
  4. Realtime Database → Rules → wklej:
{
  "rules": {
    "rooms": { ".read": true, ".write": true },
    "games": { ".read": true, ".write": true }
  }
}
